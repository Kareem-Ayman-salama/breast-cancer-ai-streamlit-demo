# Client Deliverables

This folder contains the polished delivery package for the breast cancer AI project.

## Files

- `breast_cancer_ai_unified_client_notebook.ipynb`: one organized notebook with EDA, metrics, figures, and result tables.
- `streamlit_app.py`: interactive demo for the client.
- `final_client_report.md`: client-facing report with numbers and figures.
- `final_client_report.html`: browser-friendly report with rendered figures.
- `breast_cancer_ai_client_report.docx`: Word version of the client-facing report.

## Run Streamlit

Open PowerShell:

```powershell
cd "E:\Freelance work\nour\client_deliverables"
python -m streamlit run streamlit_app.py
```

Then open the local URL printed by Streamlit.

## Scientific caveat

Cancer signature prediction, future incidence risk, subtype prediction, and prognosis are separate clinical questions. The report keeps them separated to avoid overstating the model.
